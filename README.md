# Car Sales Performance Analysis

## Tools Used
Power BI

## Project Overview
This  project analyzes over a decade sales performance of car brands and dealerships in the US.
It explores profit margins, best selling car brands and makes, the best performing dealerships and most profitable states.

## What I Learned
- How to clean messy data using power query
- How to create measures and DAX functions
- How to visualize insights in Power BI
